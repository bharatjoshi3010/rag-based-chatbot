how to rebuild db:
# In the terminal running main.py, press Ctrl+C
# Or force-kill:
Get-Process python | Stop-Process -Force


-> Drop your PDF into source_data\
-> & "d:/Code/Rag Chatbot/.venv/Scripts/python.exe" "d:/Code/Rag Chatbot/rebuild_vectorstore.py"  (rebuild)
-> & "d:/Code/Rag Chatbot/.venv/Scripts/python.exe" "d:/Code/Rag Chatbot/main.py"   (run)

note : The rebuild_vectorstore.py script must be run from the project root (d:\Code\Rag Chatbot) so the .env paths resolve correctly.

IMPORTANT: Always stop main.py BEFORE rebuilding the vectorstore.
Windows locks the Chroma DB files while main.py is running, causing the rebuild to silently save 0 chunks.
